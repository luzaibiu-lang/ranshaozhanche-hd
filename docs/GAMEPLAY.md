# 对局与操作

在 Windows 登录器输入账号和密码，勾选「记住登录」后登录，下次启动会自动填入密码。旧版仅保存了会话的玩家可能需要重新输入一次密码。临时断网时，恢复连接后可点击开始重试。

片头结束、频道门合拢后，单击「经典频道」，再点击「进入」或按 Enter。双击频道也能进入。当前玩家共享这一个频道。「刷新」会更新在线人数和房间数。进入失败可在频道页重试。

在大厅创建房间或加入已有房间。房主选择地图后，其他玩家可以在房间里看到同一张地图。房主也可以点击“AI 陪练”，为指定队伍的空位选择难度和战车。A、B、C、D 四队各有四个候选席位，一间房内真人与 AI 合计最多八位。

## 战场操作

| 操作 | 默认输入 |
| --- | --- |
| 左右移动 | ← / → |
| 调整仰角 | ↑ / ↓，或在炮口附近按住鼠标左键拖动 |
| 蓄力、开火 | 按住空格蓄力，松开发射，满蓄力时自动发射 |
| 选择武器 | 1、2、3 或 F1、F2、F3 |
| 使用背包中的四个道具 | F5 到 F8，顺序对应四个槽位 |
| 跳过当前行动 | F9 |
| 移动视野 | 鼠标移到地图边缘，或按住右键拖动 |
| 缩放视野 | 鼠标滚轮 |
| 切换全屏 | F11 |

本版本的初始 SP 为 150，完成行动恢复 80 SP，恢复受上限限制。基础炮无需消耗 SP，其他武器的消耗随车型和技能变化。能量不足时，炮口会冒烟，力量条上方显示文字提示，该次开火不会扣除 SP。

## 商城与补给

在商城单击可选中道具，双击购买；背包已满或金币不足时，购买会失败。小补给恢复 50 点生命，使用后仍可行动。大补给恢复 100 点，团队补给给存活队友各恢复 40 点，这两种道具用后都结束当前行动。黄色浮字表示生命补给，绿色浮字表示燃料补给。

当前发行平台为 Windows x64，窗口可调整尺寸、最大化或切换全屏。Web、Android 和 iOS 属于后续适配方向。
