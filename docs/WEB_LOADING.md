# 网页资源加载

0.2.6 将 Godot Web 资源拆成核心、地图、音乐、战斗特效和完整字体。登录只下载核心及当前使用的音乐，进入房间后预载该地图和战斗特效，开始与准备前再次确认资源就绪。下载失败时停留在已有界面并重试，不创建空地图战场。

| 同条件浏览器测试 | 0.2.5 | 0.2.6 |
| --- | --- | --- |
| 首次打开资源传输 | 约 130.8 MiB | 约 15.94 MiB |
| 同版本缓存后再次打开 | 大包可能重复下载 | 约 9.7 KiB 页面 |

这些数值来自本地静音 Chromium 与真实 WebAssembly，包含当时请求到的启动音乐；不代表公网固定秒数。地图、特效与后续曲目按使用下载，首次开局还需要相关资源。

引擎和静态文件使用不依赖游戏代码版本的路径，资源包使用 SHA-256 文件名。代码更新不会替换没有变化的引擎、地图与音乐 URL。Nginx 使用预压缩文件及 immutable 缓存，不在每次请求时重新压缩。资源下载同时最多两个，内容校验通过后才写入缓存并挂载。

Web 按需包放在独立 user://web-packs 目录，文件缓存清理预算 160 MiB；不会清理账号或设置。浏览器 HTTP 缓存和页面已挂载资源的内存由浏览器管理，这个预算不代表整个浏览器内存上限。系统禁用持久存储时仍可运行，但下次打开可能需要重新下载。

启动中文字体保留常用字及游戏文字，生僻字出现时加载原完整字体。音乐曲目保持原文件，没有重编码。手机虚拟键盘单独按设备启用，桌面保持键鼠界面。

回归覆盖真实地图 4 的 AI 对局、手机移动及 F2 发射、密码输入与粘贴、503、损坏包拒绝及连续失败后恢复。测试未覆盖所有真实手机型号，详见[加载验收数据](validation/web-loading-0.2.6.json)。
