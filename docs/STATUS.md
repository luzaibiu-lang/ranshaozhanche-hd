# 项目状态与核对边界

源码版本为 **0.2.8**。手机开局增加全体加载确认和首回合计时保护，聊天增加原生输入栏与发送按钮，素材预加载和小地图更新减少主线程集中工作。范围见[手机网页性能说明](MOBILE_PERFORMANCE.md)。启动和刷新必须手动登录；手机聊天退出、地图手势、道具按钮和开局流程已用真实浏览器触控事件回归。网页采用核心小包和资源按需加载，首屏实测约 15.94 MiB，缓存后再次打开约 9.7 KiB；手机软键盘输入已接通。网页加载页和战斗控件共用设备平台判定，Windows 原生客户端保持桌面模式；触屏电脑和窄窗口不再切换到手机界面。登录方块补齐实体侧壁、背面和逐面明暗，划过声使用参照中的七段原始随机音效。登录方块按划过方向翻摆并播放提示音；手机网页已实现横屏全屏入口、触控战斗按键、单指拖图和双指缩放。桌面边缘移图使用更宽的触发区。详见[手机操作与兼容范围](MOBILE_CONTROLS.md)。创建房间的输入框和下拉菜单使用中文字体。战车、地图和道具资料校验通过后才允许进入房间，读取失败会自动重试。保存 AI 配置时，客户端只从启用的 AI 席位读取车型，真人和空位使用协议默认值。

0.2.0 的实际 Web 导出与 Windows 发行包连续两次通过同房切图、双向战斗聊天、两轮六个行动位、结算回房及第二局验收。范围与限制见[多端说明](MULTIPLATFORM.md)。

频道与房间过场使用原版门音效。重制版按玩家描述为进出房间实现上下开合，中央火焰标志取自原版 `GameBack`。频道选择使用左右门。原版商城可确认有开关门机制，大厅与房间之间的门板运动方向和逐帧时序仍待原版实机对照。

## 0.1.17 聊天、回房与爬坡

对局新增内置聊天：Enter 输入和发送，Esc 取消，输入期间不触发移动、蓄力或技能快捷键。聊天发送独立于战斗命令确认。先回房的玩家可操作商城、准备及换车；打开商城先取消准备，最后一人返回不再覆盖其他人的选择。大厅区分真正对战与结算。爬坡恢复原版底盘取样和陡坡/突变/台阶限制。

最终 Windows 导出包：两客户端中文消息及射击期间聊天共 30 项、连续两局返回及真实买卖 58 项、商城与房间 361 项、操作及 250 毫秒延迟 150 项、移动与原版样本 2364 项、反馈与布局 92 项和雷达 7380 像素检查通过。Go 918 项含子测试及静态分析通过。测试在非活动桌面、Dummy 音频下完成；真实输入法候选窗口及更多设备仍需人工验证。详见[聊天与回房修复](CHAT_AND_RETURN.md)和[原版差异核查](ORIGINAL_COMPARISON.md)。

## 仍需核实

- 救护弹与致盲弹的原版精确作用半径缺少充分证据，当前保留 50 游戏像素。
- 所有高级武器的分裂时序、原版碰撞形状与每个可选弹窗，尚不能统一标为逐帧等价。
- 更广泛显卡、DPI、网络环境和其他平台需要持续实测。
- 图形素材以既有资源为基底；宽屏与高分辨率绘制不等于所有位图均已重新绘制为高清素材。

## 开发顺序

1. 先补充现有玩法的复现用例、原版证据与多人稳定性回归。
2. 再逐项核对高级武器时序、资源透明通道和交互细节。
3. 在不改变游戏身份的前提下完善显示与动画。
4. 扩展桌面浏览器兼容性测试，为移动端接入触控、软键盘、生命周期和存储。

以上为开发方向，未完成内容不作为交付承诺。
