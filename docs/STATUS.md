# 项目状态与核对边界

源码版本：**0.1.15**。这是独立重建实现，功能回归与原程序逐帧等价分别记录。

频道与房间过场使用原版门音效。重制版按玩家描述为进出房间实现上下开合，中央火焰标志取自原版 `GameBack`。频道选择使用左右门。原版商城可确认有开关门机制，大厅与房间之间的门板运动方向和逐帧时序仍待原版实机对照。

## 0.1.15 回血反馈

补给光圈及上升光点已按原版资源和函数时序补回。最终 Windows 导出包通过 85 项图形反馈检查、50 项真实购买并使用补给检查，以及 77 项战斗时间轴回归。测试在非活动 Windows 桌面上使用 Dummy 音频驱动，包含实际截图检查；原音验证通过资源绑定与播放事件检查完成。Go 全量测试及静态分析通过。详见[原版回血依据与验证范围](RECOVERY.md)。

| 平台 | 状态 |

## 仍需核实

- 救护弹与致盲弹的原版精确作用半径缺少充分证据，当前保留 50 游戏像素。
- 所有高级武器的分裂时序、原版碰撞形状与每个可选弹窗，尚不能统一标为逐帧等价。
- 更广泛显卡、DPI、网络环境和其他平台需要持续实测。
- 图形素材以既有资源为基底；宽屏与高分辨率绘制不等于所有位图均已重新绘制为高清素材。

## 开发顺序

1. 先补充现有玩法的复现用例、原版证据与多人稳定性回归。
2. 再逐项核对高级武器时序、资源透明通道和交互细节。
3. 在不改变游戏身份的前提下完善显示与动画。
4. 为 Web 和移动端逐步接入平台输入、生命周期和存储。

以上为开发方向，未完成内容不作为交付承诺。
