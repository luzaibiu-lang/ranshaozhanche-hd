# 0.2.3 手机网页操作

加载游戏时，手机浏览器可点击“旋转至全屏获得更佳体验”。按钮在用户触摸事件中请求全屏，再请求锁定横屏。退出全屏后按钮会重新显示，触碰游戏画面不会移除入口，支持反复进入；浏览器拒绝请求时也保留重试按钮。浏览器或系统限制这些 API 时会提示把手机横过来；iPhone Safari 等环境不能保证程序强制全屏或锁定方向，仍可以在横屏浏览器窗口内操作。

战斗左侧四个方向键：左右移动战车，上下调整炮角。F1、F2、F3 切换弹药。右侧圆形发射键按住蓄力、松开发射，上方的 1、2、3、4 对应四个道具槽。各按键允许独立手指同时按住，切换回合、触摸取消、旋转屏幕、失去焦点或进入弹窗会清除按住状态。取消触摸不触发发射。

单指在空白战场拖动地图，双指捏合缩小、张开放大，缩放保持双指中心的地图点位置。按键上开始的手指不会被地图接管。菜单中的缩放锁定仍生效。

桌面鼠标边缘移图触发带按窗口尺寸调整为 28–72 像素，不需要贴住最外沿；越接近边缘速度越快。登录方块已按光线飞车本地渲染的跨格翻摆时序实现，音效使用本游戏的短提示音，同一格内移动不重复触发。

## 验证范围

使用实际导出的 WebAssembly 游戏、Chromium 手机触摸模拟及独立本机 Go 服务完成移动、调角、F2 发射、道具使用和取消触摸验证。四种屏幕尺寸、三指同时按住、F1–F3、四个道具槽、空槽、取消、失去回合、弹窗与旋转共 327 项控件检查通过；摄像机 16 项拖动、捏合、锚点与复位检查通过。Windows 导出包验证了登录翻摆、跨格音效事件和频道过渡。

浏览器模拟验证不等于实体安卓和 iPhone 真机验收；全屏、横屏与浏览器音频播放仍受系统权限和用户手势要求约束。
