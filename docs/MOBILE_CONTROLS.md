# 手机网页操作与设备区分

电脑与手机共享游戏逻辑、账号和服务器，界面按设备平台区分。网页外壳与游戏使用 `源码/client/device_profile.js` 的同一份会话判定；Windows、macOS、Linux 桌面浏览器以及 Windows 原生客户端不会因触屏或窄窗口启用手机版。Android、iOS、HarmonyOS 手机和平板启用触控界面，iPad 桌面模式按 Macintosh 标识与多点触控组合识别。旋转、最大化和连接鼠标只影响布局与输入，不切换设备类型。

加载游戏时，手机浏览器可点击“旋转至全屏获得更佳体验”。按钮在用户触摸事件中请求全屏，再请求锁定横屏。退出全屏后按钮会重新显示，触碰游戏画面不会移除入口，支持反复进入；浏览器拒绝请求时也保留重试按钮。浏览器或系统限制这些 API 时会提示把手机横过来；iPhone Safari 等环境不能保证程序强制全屏或锁定方向，仍可以在横屏浏览器窗口内操作。

战斗左侧四个方向键：左右移动战车，上下调整炮角。F1、F2、F3 切换弹药。右侧圆形发射键按住蓄力、松开发射，上方的 1、2、3、4 对应四个道具槽。各按键允许独立手指同时按住，切换回合、触摸取消、旋转屏幕、失去焦点或进入弹窗会清除按住状态。取消触摸不触发发射。

单指在空白战场拖动地图，双指捏合缩小、张开放大，缩放保持双指中心的地图点位置。按键上开始的手指不会被地图接管。菜单中的缩放锁定仍生效。

桌面鼠标边缘移图触发带按窗口尺寸调整为 28–72 像素，不需要贴住最外沿；越接近边缘速度越快。登录方块已按光线飞车本地渲染的跨格翻摆时序实现，音效使用参照中的筹码短音，同一格内移动不重复触发。

## 验证范围

使用实际导出的 WebAssembly 游戏、Chromium 手机触摸模拟及独立本机 Go 服务完成移动、调角、F2 发射、道具使用和取消触摸验证。四种屏幕尺寸、三指同时按住、F1–F3、四个道具槽、空槽、取消、失去回合、弹窗与旋转共 327 项控件检查通过；摄像机 16 项拖动、捏合、锚点与复位检查通过。Windows 导出包验证了登录翻摆、跨格音效事件和频道过渡。

浏览器模拟验证不等于实体安卓和 iPhone 真机验收；全屏、横屏与浏览器音频播放仍受系统权限和用户手势要求约束。

0.2.5 的导出页面通过 13 种设备配置，包括触屏 Windows、窄窗口电脑、Linux、ChromeOS、Mac、安卓平板和 iPad 桌面模式。该矩阵使用暂停引擎的加载页模拟，实际 WebAssembly 另行验证了全屏重复进入及移动、调角、道具、F2 发射和取消触摸；Windows 实际发行包验证了桌面模式、注册和记住登录。详见[设备验收记录](validation/devices-0.2.5.json)。

0.2.6 接通 Godot Web 手机虚拟键盘，密码字段采用密码键盘。实际导出的游戏在全屏触屏模拟下验证了中文输入法组合输入、密码粘贴和登录，触屏 Windows 仍使用桌面键鼠输入；尚未在实体手机上验收。

0.2.7 每次启动和刷新均须手动提交登录，保存的会话不会自动认证。Windows 已记住的账号密码只用于预填。聊天时触摸输入框外会收起键盘并保留草稿，随后可继续操作；道具图标填充按钮内边框。

实际 WebAssembly 触控事件在全屏状态下完成登录、频道、开始对局、聊天与屏幕尺寸变化、外部触摸退出、捏合缩放、单指拖图及继续移动。另有 331 项控件检查、Windows 旧票据启动及 16 项摄像机检查。详见[本次回归](validation/manual-mobile-0.2.7.json)，浏览器模拟仍不等于实体手机验收。
